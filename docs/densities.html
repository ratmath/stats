Your own densities

Probability courses hand out densities like f(x)=cx2f(x) = cx^2f(x)=cx2 on [0,2][0, 2][0,2] and ask for ccc, the mean and the variance; then they ask for the distribution of X2X^2X2, or of the largest of three draws. fromDensity, transform and orderStatistic answer those questions, exactly whenever the density is a polynomial on each piece.

A density from a formula

A function fff is a density on its support when f≥0f \ge 0f≥0 there and ∫f=1\int f = 1∫f=1. fromDensity proves both before it builds anything. For a polynomial piece the sign is decided between its isolated real roots and the mass comes from the antiderivative, so both facts are exact. For any other formula, f≥0f \ge 0f≥0 is shown by interval evaluation on ever smaller pieces and the mass by analytic's certified integral, which must enclose 1. With { normalize: true } the formula is divided by its mass, reported as constant.

import { fromDensity, show } from "@ratmath/stats";

const X = fromDensity("x^2", [0, 2], { normalize: true });
X.constant;   // 3/8: ∫₀² x² dx = 8/3
X.mean;       // 3/2 = ∫ x · (3/8)x² dx
X.variance;   // 3/20
X.cdf(1);     // 1/8 = (1/2)³
fromDensity("x", [0, 2]);   // refused: the total mass is 2, not 1

A list of pieces gives a piecewise density. Each piece is [formula, [a, b]], in order and meeting end to end. The triangle on [0,2][0, 2][0,2], the sum of two uniforms, is

const T = fromDensity([["x", [0, 1]], ["2 - x", [1, 2]]]);
T.mean;        // 1
T.variance;    // 1/6 = 1/12 + 1/12
fromDensity("exp(-x)", [0, "inf"]).cdf(1);   // ≈ 0.632121 = 1 − 1/e

checks records how f≥0f \ge 0f≥0 and the mass were established, so a reader can see which facts are exact and which rest on an enclosure.

A function of a random variable

For ggg increasing on the support, P(g(X)≤y)=P(X≤g−1(y))P(g(X) \le y) = P(X \le g^{-1}(y))P(g(X)≤y)=P(X≤g−1(y)), and the density is f(g−1(y))/∣g′(g−1(y))∣f(g^{-1}(y)) / |g'(g^{-1}(y))|f(g−1(y))/∣g′(g−1(y))∣. Decreasing ggg flips the inequality. transform proves ggg monotone from the sign of g′g'g′ over the whole support (and refuses otherwise), encloses g−1(y)g^{-1}(y)g−1(y) by bisection, and keeps the mean and variance exact when XXX has polynomial pieces and ggg is a polynomial.

import { uniform } from "@ratmath/stats";

const Y = uniform(0, 1).transform("x^2");
Y.cdf("1/4");   // ≈ 1/2: P(X² ≤ 1/4) = P(X ≤ 1/2)
Y.pdf("1/4");   // ≈ 1 = 1/(2·√(1/4))
Y.mean;         // 1/3 = E[X²]
uniform(-1, 1).transform("x^2");   // refused: not monotone on [−1, 1]

Order statistics

The kkk-th smallest of nnn independent draws, X(k)X_{(k)}X(k)​, has P(X(k)≤x)=∑j≥k(nj)F(x)j(1−F(x))n−jP(X_{(k)} \le x) = \sum_{j \ge k} \binom n j F(x)^j (1 - F(x))^{n-j}P(X(k)​≤x)=∑j≥k​(jn​)F(x)j(1−F(x))n−j and density n!(k−1)! (n−k)!Fk−1(1−F)n−kf\frac{n!}{(k-1)!\,(n-k)!} F^{k-1} (1-F)^{n-k} f(k−1)!(n−k)!n!​Fk−1(1−F)n−kf. For a uniform or polynomial density these are polynomials again, so the result has exact moments. The maximum of nnn uniforms on [0,1][0, 1][0,1] has density nxn−1n x^{n-1}nxn−1, which is Beta(nnn, 1).

const M = uniform(0, 1).orderStatistic(3, 3);   // the largest of three
M.mean;         // 3/4 = n/(n+1)
M.variance;     // 3/80
M.pdf("1/2");   // 3/4 = 3 · (1/2)²
