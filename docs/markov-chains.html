Chains and beliefs

Markov chains

A Markov chain moves between finitely many states, choosing each step with probabilities that depend only on where it is. Everything a course asks of one, from the long-run share of time in each state to the chance of ending in each absorbing state, comes from linear algebra over the rationals, so here it is exact.

A chain and its long run

import { markovChain } from "@ratmath/stats";

const weather = markovChain({ sun: { sun: "9/10", rain: "1/10" }, rain: { sun: "1/2", rain: "1/2" } });
weather.distribution("rain", 3);        // { sun: 39/50, rain: 11/50 } three days after rain
weather.stationary().distribution;      // { sun: 5/6, rain: 1/6 }
weather.meanReturnTime("rain");         // 6 = 1/π(rain)
weather.hitting("rain").expected.sun;   // 10 days from sun to the next rain
weather.simulate("sun", 12, { seed: 3 }).join(" ");

With PijP_{ij}Pij​ the probability of moving from iii to jjj, the distribution after nnn steps is μPn\mu P^nμPn, and power(n) computes PnP^nPn by repeated squaring. A stationary distribution solves π=πP\pi = \pi Pπ=πP with ∑πi=1\sum \pi_i = 1∑πi​=1: one linear system, solved exactly. For an irreducible chain it is unique, and by Kac's lemma the expected time to return to state iii is 1/πi1/\pi_i1/πi​.

Classes and periods

const cycle = markovChain([[0, 1, 0], [0, 0, 1], [1, 0, 0]]);
cycle.classes();     // [{ states: [0, 1, 2], closed: true, recurrent: true, period: 3 }]
cycle.isErgodic();   // false: Pⁿ cycles and never settles, though π = (1/3, 1/3, 1/3) exists

States communicate when each can reach the other; the classes are found from reachability. In a finite chain a class is recurrent exactly when no probability leaves it. The period of a class is the greatest common divisor of the lengths of its cycles, found from a breadth-first search. An irreducible chain with period 1 is ergodic: PnP^nPn converges to a matrix whose rows all equal π\piπ.

Absorption

// gambler's ruin with fair bets, from 0 to 4 dollars
const ruin = markovChain([[1, 0, 0, 0, 0], ["1/2", 0, "1/2", 0, 0], [0, "1/2", 0, "1/2", 0],
                          [0, 0, "1/2", 0, "1/2"], [0, 0, 0, 0, 1]]);
const a = ruin.absorption();
a.probabilities[1];   // { "0": 3/4, "4": 1/4 }
a.steps;              // { 1: 3, 2: 4, 3: 3 }: k(N − k) bets on average

Order the states with the transient ones first, so that P=(QR0I)P = \begin{pmatrix} Q & R \\ 0 & I \end{pmatrix}P=(Q0​RI​). The fundamental matrix N=(I−Q)−1=I+Q+Q2+⋯N = (I - Q)^{-1} = I + Q + Q^2 + \cdotsN=(I−Q)−1=I+Q+Q2+⋯ counts the expected visits to each transient state. Then NRNRNR gives the absorption probabilities and N1N\mathbf 1N1 the expected number of steps before absorption. Each is exact; fundamental returns NNN itself.
