Reference

Every export, grouped by subject. Wherever a number is expected you may pass a Rational, a BigInt, text such as "1/3" or "0.05", or a JS number, which is read by its decimal form (0.1 is one tenth).

Kinds of answer

KindWhat you get
exactA Rational. Finite probability, discrete distributions with rational parameters, statistics of exact data, exact tests.
certifiedA RationalInterval that contains the true value; { bits } sets its width. Continuous distributions, Poisson, square roots.
simulatedAn object with kind: "simulated", its seed, and its sampling error.

Arguments the library cannot work with are refused with a StatsError carrying a code, such as bad-argument, domain, needs-exact, too-large, too-close or impossible-event.
