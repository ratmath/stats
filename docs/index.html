@ratmath/stats

Probability and statistics that say how they know

Probability and statistics in one library. Every answer is labelled exact, certified or simulated, and data can be generated from a model you choose, disturbed with noise from another distribution, and handed to the tests and regressions to see whether they recover what was put in.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Finite probability: events, conditional probability, Bayes, random variables, joint tables, all exact.
  • Discrete and continuous distributions with certified probabilities and quantiles.
  • Descriptive statistics and exact tests.
  • Seeded generation of data from a known model, with noise and contamination from other distributions, and experiments that repeat a procedure many times.
  • Estimation, confidence intervals and the standard tests.
  • Regression and analysis of variance.
  • Rank tests, permutation tests and the bootstrap.
  • Markov chains and conjugate Bayesian updating.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
